# MiniERP

Desktop ERP application for small and medium businesses. Inventory, purchasing, sales, production, payments, and financial reporting — one app for Windows, macOS, and Linux.

Built for teams that need their day-to-day business operations in one place, without enterprise ERP complexity.

## Download

Get the latest installer for your platform from the [Releases page](https://github.com/mfbgull/minierp-flutter/releases).

## Deployment Model

MiniERP is a **two-component application**:

1. **Flutter Desktop Client** — UI for inventory, sales, purchases, production
2. **Node.js Server** — API backend with SQLite database

### Linux (Recommended)

The Linux release includes a **self-contained .run installer** that bundles both client and server:

```bash
chmod +x MiniERP-*.run
./MiniERP-*.run
```

This installs to `~/.local/share/minierp/` and includes:
- Flutter desktop client
- Node.js server
- Bundled Node.js runtime
- SQLite database (auto-initialized on first run)
- Launcher script that starts server then client

**Alternative Linux packages** (client only — requires separate server):
- `.deb` package — install with `dpkg -i`
- `.AppImage` — portable, no installation required

### Windows

The Windows installer includes the **client only**. You must run the server separately:

1. Install Node.js (v18+)
2. Clone or download the server from `server/`
3. Run `npm install && npm run build && npm start`
4. Launch MiniERP — it connects to `localhost:3011`

### macOS

The macOS DMG includes the **client only**. You must run the server separately:

1. Install Node.js (v18+) via Homebrew: `brew install node`
2. Clone or download the server from `server/`
3. Run `npm install && npm run build && npm start`
4. Launch MiniERP — it connects to `localhost:3011`

## Server Configuration

The server runs on port 3011 by default. Configure via environment variables:

```bash
PORT=3011
HOST=0.0.0.0
NODE_ENV=production
JWT_SECRET=<auto-generated>
DEFAULT_ADMIN_PASSWORD=admin123
ALLOWED_ORIGINS=http://localhost:3011,http://127.0.0.1:3011,file://
```

## Development

### Prerequisites

- Flutter 3.47.2+
- Node.js 18+
- npm

### Running locally

```bash
# Start server
cd server
npm install
npm run build
npm start

# Start client (in another terminal)
flutter pub get
flutter run
```

The client connects to `http://localhost:3011/api` by default. Override with:

```bash
flutter run --dart-define=API_BASE_URL=http://your-server:3011/api
```
