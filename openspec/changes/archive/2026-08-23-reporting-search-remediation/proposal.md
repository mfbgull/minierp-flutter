# Proposal: reporting-search-remediation

## Why

The reporting/global-search/duplicated-business-logic audit (`opus5-audit-report/reports.md`) found 26 defects. Four are already remediated by in-flight work and are **out of scope**: SRCH-01 (missing bind param), REP-06 (mobile COGS uses real batch cost), REP-15 (invoice delete voids journal lines), REP-18 (computed-column expression validator). What remains, verified against current source: the balance sheet is still assembled from unrelated transactional sources (`Reports.ts:623+`) while the trial balance reads the GL — the two screens disagree by ₨95,015 on inventory alone; cash has two irreconcilable definitions (+3,000 GL vs −20,100 operational, REP-03); P&L and balance-sheet COGS diverge on `movement_type='OUT'` with the SQL duplicated three times (REP-05); routed KPIs count Cancelled/Returned revenue and compute tax on tax-inclusive bases (REP-07); `getGeneralLedger` serves the customer subledger (REP-04); customer statements annihilate their own LEFT JOIN when a specific customer is selected (REP-08); 17 of 35 exported report functions are unrouted dead code carrying divergent formulas (REP-09/10/11); six controller defaults use UTC dates (REP-12); `activityLogger.getStats` drops the last day of every range (REP-13); ledger statement opening balances lack an id tiebreaker (REP-14 residue); three Flutter screens ignore the global report range (REP-16); two client endpoints 404 permanently (REP-17); global search returns all rows to any authenticated user regardless of read permissions (SRCH-02) via a per-row N+1 (SRCH-03), surfacing cancelled/inactive records (SRCH-04) with dead ranking helpers and a 5× over-cap result limit (SRCH-05); and unusable leading-wildcard indexes tax 15 hot tables for zero read benefit (SRCH-07). System custom-report templates remain creatable by any `reports:create` holder (REP-19).

## What Changes

- **GL becomes the single accounting truth** (completes the direction already fixed by `gl-posting-matrix` + `balance-truth-sources`): rebuild `getBalanceSheet` from `getAllAccountBalances` grouped by `chart_of_accounts.type`; resolve cash from the five per-method accounts (1000/1010/1020/1030/1040); `cashService.collectFlows` derives account balances from those GL accounts instead of independently re-aggregating payments/expenses (classification/bucket logic stays). One-time idempotent migration backfills journal entries for documents created before posting went live (data volume is tiny: 5 invoices, 3 POs, 9 payments) and seeds opening equity.
- **Formula consolidation**: one `netRevenueExpr` fragment (`total_amount − returned_amount`, excluding Cancelled) applied to daily/monthly sales, DSO, customer statements and any remaining raw `SUM(total_amount)` site; one `cogsForPeriod(db,from,to)` helper replacing the three duplicated COGS queries; add `invoice_items.tax_amount`/`net_amount` (tax-exclusive base) with backfill so `getTaxSummary` stops taxing tax.
- **Report correctness**: real general ledger from `journal_lines ⋈ chart_of_accounts` (old query renamed `getCustomerLedgerReport`); customer statements rebuilt from `customer_ledger` with opening-balance carry-forward and the WHERE/ON branch bug fixed; `todayLocal(db)` helper replaces the six UTC controller defaults and aligns `ledgerUtils` writes; statement opening-balance lookup gains an `, id` tiebreaker; implement `/reports/expiry` + `/dashboard/expiry-alerts` over `stock_batches.expiry_date`; wire the three missing Flutter range pairs (general ledger, income statement, tax summary).
- **Search hardening**: each entity search runs only when the caller holds `<module>:read`; permission set resolved once per request (kills the ~650-row × 3-query N+1); `is_active = 1` on warehouses/employees, Cancelled invoices excluded; per-entity limit capped at 10; delete dead `rankClause`/`rankParams`.
- **Custom reports**: `createTemplate` requires an admin role (system templates are visible to everyone).
- **Dead code deletion**: remove the ~17 unrouted report functions after confirming zero non-route imports — each carries a divergent formula waiting to be re-exposed.
- **Index hygiene**: drop the plain single-column search indexes that `%term%` LIKE can never use (keep any serving other queries); keep LIKE search, no FTS5 at current scale (~45 searchable rows).

## Capabilities

### New Capabilities
- `report-query-integrity`: every routed report derives money figures from shared, single-definition helpers; period defaults are local-date correct; statements foot (opening + debits − credits = closing); the general ledger reflects the GL, not a subledger; unrouted report functions do not ship divergent duplicate formulas.
- `search-permission-filtering`: global search returns entity rows only where the caller holds module read permission; results respect record status (no cancelled/inactive); permissions resolve once per request; per-entity result caps enforced.

### Modified Capabilities
- `balance-truth-sources`: the balance sheet's three sections are GL-derived (grouped by account type) rather than assembled from transactional tables; inventory/AR/AP/cash in the sheet come from the same source as the trial balance.
- `gl-posting-matrix`: historical documents created before live posting are backfilled once via migration (plus opening-equity entry), so trial-balance and balance-sheet data reflect reality without a cutover gap.
- `authz-hardening`: global search enforces row-level module read permissions; custom-report system templates are admin-gated.

## Impact

- **Server code**: `models/Reports.ts` (balance sheet, GL, statements, revenue/tax/COGS helpers, dead-function deletion), `services/cashService.ts` (GL-backed balances), `controllers/reportsController.ts` (local-date defaults), `services/searchService.ts` + `controllers/searchController.ts` + `routes/search.ts`, `controllers/customReportsController.ts` + `routes/customReports.ts`, delete `services/activityLogger.ts#getStats` + its re-export, `utils/ledgerUtils.ts`, `models/Customer.ts`, new `reports/expiry` + `dashboard/expiry-alerts` handlers.
- **Database**: additive/idempotent migrations only — `invoice_items.tax_amount`/`net_amount` backfill; GL backfill for pre-posting documents + opening equity; drop unused search indexes. No destructive schema change.
- **Flutter client**: `lib/features/reports/report_providers.dart` (three range pairs). No API contract breaks; new endpoints are additive.
- **Risk notes**: dashboard/reconciliation expected-cash figures change to match GL (by design — they disagree today by ₨23,100); deleting the dead report functions removes unreferenced code only (import check gated); search result payloads shrink for permission-limited users (intended).
