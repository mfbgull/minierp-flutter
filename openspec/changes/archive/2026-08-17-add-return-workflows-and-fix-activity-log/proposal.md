## Why

Users cannot initiate returns from purchase and invoice workflows, and the activity log grid is not surfacing data. This blocks a common business operation and reduces operational visibility. Fixing these gaps restores return processing and makes activity logging usable again.

## What Changes

- Add a dedicated action to create purchase returns from the purchase return screen.
- Add a return option to the 3-dot menu on purchase orders and purchases.
- Add a return option to the 3-dot menu on invoices and to the invoice detail view.
- Fix the activity log screen so its grid actually displays data.

## Capabilities

### New Capabilities
- `purchase-returns`: Introduce purchase return entry and routing from related documents.
- `invoice-returns`: Introduce invoice return entry and routing from related documents.
- `activity-log-grid`: Repair the activity log grid data path so records render correctly.
